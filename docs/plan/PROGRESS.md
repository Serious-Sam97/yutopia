## Map structure upgrade (2026-10-10)
Maps are now **per-space data** (`yutopia_spaces.layout`, null = the built-in Studio Building), edited in build mode. One set of rules in `packages/shared/src/map-edit.ts` + `grid.ts` serves the client preview and the server.
1. **Walls:** Walls tool paints walls, any floor finish, or empty space by click-drag. Refused (with a reason): walling over furniture, people, doors or the arrival point, or removing the wall a board/screen hangs on.
2. **Rooms & desks for a person:** Rooms tool — drag a rectangle → name, owner (project members), sound (private/open/booth), floor, optional walls + door built around it. A sign over the door shows "ROOM · Owner". Desks tool — click any seat to give it to someone: they always land there; a nameplate shows on it (one assigned desk per person).
3. **Doors:** placed in a one-tile gap between walls; open / closed (swings open as people pass) / locked. Only the room's owner locks/unlocks (project owners can unlock in an emergency); **while locked only the owner can walk in or out** — enforced server-side per person (each person has their own walk grid), and pathfinding, teleport and "join them" respect it.
4. **Map size:** presets S 32×24 · M 48×36 · L 64×48 · XL 80×60 · XXL 96×72 or custom 16–96; resize keeps content top-left (furniture beyond the edge removed), or start blank; set the arrival point.
- Yondra: migration `2026_10_12_000001_add_layout_to_yutopia_spaces`, signed `PUT /internal/yutopia/spaces/{id}/layout` (shape-validated), `GET /api/yutopia/spaces/{id}/members`; seeder adds the **Yutopia Lab** sandbox project.
- Tests: shared +5 (painting guards, resize, blank, rooms + locked doors), world-server +3 (paint permissions, owned room + lock incl. a tampered client pushing into the doorway, desks + resize), backend +1, e2e `map-edit.spec.ts` (blank map → room with owner → walls → desk → lock → Bia kept out → resize).
